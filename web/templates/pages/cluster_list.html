Hosts that carry each other

Clusters

A guest is a child of the hypervisor it actually runs on, and losing that host takes it — which is right for a standalone box and wrong for a cluster, where the guests come back on a surviving member. This is the one page whose values change what a simulation concludes, not just what a report shows.
